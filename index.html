2. Objectives & Methodology of Proposed Work 3 Marks

Primary Objectives: (1) Provide high-fidelity lexical and semantic alignment between resumes and JDs; (2) Eliminate candidate rejection blind spots; (3) Produce mathematically grounded, transparent multi-dimensional scoring.

6-Stage Pipeline Methodology:
1. Document Ingestion: Multi-format text extraction (PDF / DOCX / TXT)
2. Preprocessing & Cleaning: URL/Email masking → Regex tokenization → Stopword elimination
3. Entity Extraction: Normalized regex matcher across 43 canonical tech & soft skills
4. Vector Space Modeling: Smoothed TF-IDF calculation with cosine similarity
5. Multi-Attribute Evaluation: Section integrity + Action verb/metric impact + Flesch readability
6. Feedback Synthesis: Context-sensitive remediation plan (High, Medium, Low)

3. Relevance of Algorithms & Techniques 3 Marks

Composite Scoring Equation:
Score = 100 × (0.40 · SkillFit + 0.20 · ScaledTFIDF + 0.15 · Structure + 0.15 · Impact + 0.10 · Readability)

• Skill Fit (40%): |Sresume ∩ SJD| / |SJD| over canonical skill taxonomy
• TF-IDF Cosine (20%): cos(θ) = (vr · vj) / (||vr|| ||vj||) with smoothed IDF
• Structure (15%): Detection of 6 core ATS sections (Contact, Education, Experience, Skills, Projects, Achievements)
• Impact (15%): Word-boundary detection of 21 action verbs (60%) + quantified metrics (40%)
• Readability (10%): Flesch Reading Ease = 206.835 − 1.015(words/sentences) − 84.6(syllables/words)
